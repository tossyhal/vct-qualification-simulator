## 画面

3つ。

| 画面 | 役割 | 経路 |
| --- | --- | --- |
| 通過確率 | 順位別の確率を表で読む | `/` |
| 説明 | モデルの前提と大会規定を読む | 公開ページ内。ヘッダー右端から切り替え |
| 管理者 | 日次更新の状態確認と手動実行 | `/admin`。別URL |

大会の切り替えはヘッダー下のタブ（`Pacific`）。説明は**大会タブと同じ列に置かない**。大会が増えたとき、大会名の並びに異質な項目が混ざるため、ヘッダー右端へ分ける。

グループ（Alpha / Omega）はタブで切り替える。同時に表示しない。グループは独立していて順位の比較に意味がないため。

## 配色

白地にコバルトと朱赤。面の塗りは最小限で、罫は横のみ。

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--bg` | `#ffffff` | 地 |
| `--ink` | `#161d2b` | 主要な文字 |
| `--muted` | `#617087` | 副次的な文字、ラベル |
| `--rule` | `#d7dee8` | 罫線 |
| `--strong` | `#0a2c73` | 見出し、強い強調 |
| `--route` | `#205ec6` | 直通（Playoff）列の数値 |
| `--accent` | `#d43b2d` | 順位別確率の数値 |
| `--alert` | `#a52e24` | 失敗状態（管理者ページ） |
| `--zero` | `#5f6d7d` | 確率ゼロ |

### 触ってはいけない点

**この配色はコントラストを実測して決めている。**目分量で明るくしない。実測で全テキストが基準（4.5:1、大きい文字は3:1）を満たし、最小値は 4.71:1。

とくに `--zero` は、以前 `#a9b2bd` で **2.15:1** しかなく読めなかったものを修正した値である。ゼロは「わずかな確率」ではなく「その順位はあり得ない」を意味するので、他の低い値と同じ見え方にしない。

## 書体

| 範囲 | 書体 | ライセンス |
| --- | --- | --- |
| 数字と数値記号（`0-9` `%` `<` `–`） | Work Sans | SIL OFL 1.1 |
| その他のラテン文字と記号 | Public Sans | SIL OFL 1.1 |
| 日本語 | システムフォントスタック | — |

`@font-face` で `unicode-range` により振り分ける。

- Work Sans: `U+0025, U+0030-0039, U+003C, U+2013`
- Public Sans: `U+0000-0024, U+0026-002F, U+003A-003B, U+003D-00FF, U+2014, U+2026, U+2212`

**Work Sans に `size-adjust: 107%` を指定する。**Public Sans の大文字高 146 に対し Work Sans の数字高が 136 で、そのまま混ぜると数字だけ小さく見えるため。「4–0」「<1」「100」のように数字と記号が隣り合う箇所で確認する。

日本語は埋め込まない。容量が現実的でないため。

**使用禁止**: fonts-urw-base35（Nimbus系）。AGPL-3 でフォント例外が PostScript / PDF 埋め込みに限定され、Web埋め込みは範囲外。

## 確率テーブル

8列。列幅は `<colgroup>` の `<col style="width:…">` で指定する。

| 列 | 内容 |
| --- | --- |
| チーム | 現在順位（小）＋略称（太）／成績 |
| Playoff | 1位＋2位の合算 |
| 1〜6位 | 順位別確率 |

- 1〜6位を均等な重みで並べる。特定順位への集約を主役にしない
- ヘッダーは1行。行き先の帯は置かない
- 確率ゼロは `0` と表記し、`--zero` で示す。打消し線は使わない

### 列幅の罠

`table-layout: fixed` は**最初の行**から列幅を決める。ヘッダーが複数行になると2行目以降の幅指定は効かない。**必ず `<colgroup>` で指定する。**

旧実装にあった `table { min-width: 930px }` を復活させない。これが横スクロールの原因だった。

## 管理者ページ

運用者ひとりが、日次更新が動いているかを確かめ、必要なら手動で取り込むための画面。公開画面と同じデザイン言語で作る。

扱う状態は4つ。**成功・変更なし・失敗を色だけで区別しない。**文言か記号を併用する。

| 状態 | 表示 |
| --- | --- |
| 成功 | 開始・終了時刻、実行時間 |
| 変更なし | 同上 |
| 失敗 | 概要と、次に何をすればよいか |
| 実行中 | 手動更新を無効化し、二重送信を防ぐ |

あわせて、最新スナップショットの取得日時・source revision・content hash、最新シミュレーションの生成日時・seed・iterations・実行時間を表示する。

手動更新は確認を挟んでから実行する。エラー表示に秘密情報や外部レスポンスの生データを含めない。

**#7 が完了するまで、管理者ページは本番ビルドから到達できないようにする**（ビルドフラグで除外するか、ルーティングへ登録しない）。認証境界と管理APIは #7 の担当。

## 画面の状態

公開ページは3系統だけ実装する。古いデータや欠損の防止は Worker 側の責務とし、フロントへ持ち込まない。

| 状態 | 扱い |
| --- | --- |
| 読み込み中 | `aria-live` で通知 |
| 取得成功 | 盤面を表示 |
| 取得失敗 | 理由を示し、再試行できる。`aria-live` で通知 |

**取得失敗でページ全体を差し替えない。**説明はAPIを必要としない静的な内容なので、取得に失敗している間も読める必要がある。状態の差し替えは大会タブの中だけに閉じる。

APIレスポンスに欠損があった場合、黙って非表示にせず欠損として表示する。

## 守る下限

実装でも満たすこと。すべて実測で確認する。

- 幅375pxで `document.documentElement.scrollWidth === 375`
- コントラストが 4.5:1 以上（大きい文字は 3:1）。基準割れ0件
- 操作要素のタッチターゲットが 44×44px 以上。ただし本文中のインラインリンクは対象外（WCAG 2.5.5 の例外）
- キーボードだけでタブ切替と全チームの確率へ到達できる
- `:focus-visible` の可視フォーカス
- `prefers-reduced-motion: reduce` で動きを止める
- タブは WAI-ARIA Tabs パターン（`aria-selected`、`aria-controls`、左右矢印、roving tabindex）
