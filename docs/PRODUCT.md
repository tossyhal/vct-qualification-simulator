# PRODUCT

このサイトが誰の何を助けるかを定める。画面を設計・実装するときの判断基準はここに置く。

## 役割

総当たりのグループステージは、進行中に「今どこが優勢か」が読み取りにくい。勝敗表を見ても、残り試合との兼ね合いで各チームがどのくらい有利なのかは分からない。そこを補うのがこのサイトである。

**現在開催中のグループ総当たり大会を見るためのサイト**と位置づける。

## 対象としないもの

| 対象外 | 理由 |
| --- | --- |
| トーナメント形式の大会 | ブラケットを見れば分かる。Liquipediaなど既存サイトで足りる |
| 終了した大会 | 結果が出ているので確率を見る意味がない |
| 運営やアナリスト向けの精密な分析 | 残り試合を一律50%とするモデルはその用途に耐えない |

## 対象利用者

VCT Pacificを追っていて、応援しているチームがあるファン。試合は見るが、順位表の読み解きやタイブレーク規定には詳しくない。

この利用者は次を知りたい。

1. 応援チームが今どのくらい有利なのか
2. その有利さが、何につながるのか

2つ目が重要になるのは、このリーグでは**グループステージで敗退するチームがないため**である。順位が決めるのは「通過か敗退か」ではなく「次をどこから始めるか」になる。

| 順位 | 行き先 |
| --- | --- |
| 1位 | Playoffs Upper Bracket準決勝へbye |
| 2位 | Playoffs Upper Bracket 1回戦 |
| 3・4位 | Play-In Upper Bracket 2回戦 |
| 5・6位 | Play-In Upper Bracket 1回戦 |

出典は[Liquipedia](https://liquipedia.net/valorant/VCT/2026/Pacific_League/Stage_2)。

したがって6順位すべてに固有の意味がある。「上位2チームが通過」という切り口だけでは、1位のbyeという最大の報酬も、5位と3位の差も表現できない。**順位別確率がこの画面の主題であり、直通確率はその要約のひとつ**という関係になる。

## 利用場面

想定するのは次の3つ。いずれも短時間で、多くはモバイル。

- **試合直後** — 今日の結果で順位と見通しがどう動いたか確かめる
- **試合前** — 今日の試合が応援チームにとってどのくらい重いか知る
- **節目** — 残り試合が減ってきた時期に、応援チームの現実的な着地点を確かめる

## 成功条件

1. 応援チームを順位表から見つけ、その1〜6位の確率を読める
2. 各順位が何につながるかが、大会規定を知らなくても分かる
3. 表示している確率が何の計算結果か（試行回数、残り試合の扱い）を確かめられる
4. モバイルで、横スクロールに頼らず1〜6位の確率を読める
5. データを取得できないとき、その事実が分かり、再試行できる

## 設計上の決定

| 決定 | 理由 |
| --- | --- |
| 表形式を維持する | 12チーム×6順位は表が最も読みやすい。グラフ化しても値の比較が難しくなるだけ |
| 1〜6位の確率を均等な重みで並べる | 6順位すべてに固有の意味があるため |
| 直通確率（1位＋2位）の列は残す | 最も知られた切り口であり、要約として有用 |
| グループ間の比較を主目的にしない | グループは独立しており、順位の意味もグループ内で閉じている |
| 進行度（残り試合数）は出さない | 現在成績で足りる。列を増やす価値がない |
| モデル前提は説明タブへ置く | 常時見せるものではないが、確かめられる必要がある |
| チームロゴは出さない | 権利の扱いが確認できていない |

## 将来
