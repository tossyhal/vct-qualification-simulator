# 書体の確定と原本の再生成

書体が決まった。**アルファベットは Public Sans（現在の案5）、数字は Work Sans（現在の案6）**の組み合わせ。

## 手順1: mock.html を1案に確定させる

`docs/design/mock.html` から書体の切り替え機構を外し、上の組み合わせだけにする。

- `?type=` の切り替え、切り替えボタン、左右矢印キーでの書体切り替えを削除する
- **不採用の4書体（TeX Gyre Heros Cn、Cantarell、TeX Gyre Pagella、Atkinson Hyperlegible Next）の埋め込みを削除する。**ファイルが1.6MBあるのは6書体ぶん埋め込んでいるため。2書体だけにする
- 画面下部の書体名・ライセンス表記は、採用した2書体ぶんに直す

**グループタブ（Alpha / Omega）と大会タブ（Pacific）の切り替えは残す。**これはデザインの一部。

### 書体の分割

`unicode-range` で振り分ける。

- **数字（U+0030–0039）は Work Sans**
- **それ以外のラテン文字と記号は Public Sans**
- 日本語はシステムフォントスタックへ落とす（現状どおり）

`%`、`<`、`–`（en dash）のような、数値と並んで出る記号をどちらへ寄せるかは、実際に並べて見て自然なほうを選ぶこと。判断した内容を報告する。

### 混植の調整

2書体は x-height と字幅が違うので、そのまま混ぜると数字だけ大きく（または小さく）見える。`@font-face` の `size-adjust` などで**光学的に揃える**こと。「4–0」「<1」「100」のように数字と記号が隣り合う箇所で確認する。

## 手順2: 検証

次を実測して報告すること。

- 375pxでの `document.documentElement.scrollWidth`（375であること）
- コントラスト比が基準（4.5:1、大きい文字は3:1）を下回るものが0件であること
- タブのタッチターゲットが44×44px以上であること
- 確定後のファイルサイズ

ブラウザが起動できない場合は、その事実を報告すること。**実測できていないものを「確認済み」と書かない。**

## 手順3: 原本の再生成

確定した `mock.html` を正本として、`docs/design/` の次を作り直す。

- `probability-board.fig`（375とデスクトップの2フレーム）
- `probability-board-mobile.png`
- `probability-board-desktop.png`

手順は `docs/design/openpencil-japanese.md` にある。日本語描画は解決済み・恒久化済みなので、PATH上の `openpencil` をそのまま使う。画像レイヤーでの回避はしない。

**原本でも書体の振り分けを再現すること。**数字のテキストノードは Work Sans、それ以外は Public Sans。フォント登録は日本語と同じ仕組みで追加できるはず。

**モック確認用の「幅」切替は原本に含めない。**大会タブとグループタブは含める。

## 変えないもの

配色、余白、罫線、表構造、タブ構成、データ、文字サイズ、コントラスト、タッチターゲット。書体以外は触らない。

## 制約

- `docs/design/` 以外を触らない
- コミットしない
- 依存を追加しない
- 中間ファイルは `/tmp` へ
