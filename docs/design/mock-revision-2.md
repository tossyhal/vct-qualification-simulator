# モック修正2回目と原本の再生成

`docs/design/mock.html` を修正し、そのあと OpenPencil の原本とPNGを作り直す。

**新しくデザインしない。**指定された4点だけを変える。

## 手順1: mock.html の修正

### 1. 見出しを1行に

「VCT QUALIFICATION」が `<br>` で2行になっている。**改行なしの1行**にする。狭い画面で収まるよう、必要ならフォントサイズを調整してよい。

### 2. 大会切替タブを作る

現在「2026 PACIFIC · STAGE 2」と書かれている位置を、**大会を切り替える横並びのタブ**にする。

- ラベルは短くてよい（例: `Pacific`）
- 大会は現時点で1つだけ。**タブの枠組みだけ作る**。項目をハードコードした1件の配列から組み立て、配列を増やせばタブが増える構造にする
- 将来ここに他大会が並ぶ前提の見た目にする

### 3. グループ切替をコンテンツ側へ移す

現在「GROUP ALPHA」という見出しになっている。ここを **`Alpha` と `Omega` の横並びタブ**にする。

- 見出しの文言は `Alpha` / `Omega` だけ。「GROUP」は付けない
- モック上部にある「グループ」の切り替えコントロールは、重複するので**削除する**
- 上部の「幅」（375px / 全幅）の切り替えは残す。これはモック確認用の枠なので残す

### 4. ゼロの打消し線を消す

確率ゼロに引いている打消し線を消す。ゼロと他の低い値の区別は、色や濃度など打消し線以外の方法で付ける。

### タブの実装

大会タブもグループタブも WAI-ARIA Tabs パターンに従う。`role="tablist"` / `role="tab"` / `role="tabpanel"`、`aria-selected`、`aria-controls`、左右矢印キーでの移動、選択中のみ `tabIndex=0`。

2つのタブ列は独立して動くこと。

### 変えないもの

配色、書体、余白、罫線、8列の表構造（チーム／Playoff／1位〜6位）、ヘッダー1行、データ。

## 手順2: 原本の再生成

修正後の `mock.html` を正本として、`docs/design/` の次を作り直す。

- `probability-board.fig`（375とデスクトップの2フレーム）
- `probability-board-mobile.png`
- `probability-board-desktop.png`

**手順は `docs/design/openpencil-japanese.md` に全部書いてある。まず読むこと。** 日本語描画の問題は解決済みで、`~/.config/ai/openpencil-node-compat.mjs` へ恒久化済み。PATH上の `openpencil` をそのまま使えば日本語が出る。画像レイヤーでの回避はしないこと。

タブはAlphaを選択した状態のスナップショットでよい。

**モック確認用の「幅」（375px / 全幅）の切り替えは、原本には含めない。**あれはHTMLで見るための枠であって、デザインの一部ではない。原本は375とデスクトップの2フレームを別々に作るので、切り替え自体が不要になる。

大会タブ（Pacific）とグループタブ（Alpha / Omega）はデザインの一部なので、原本にも含める。
