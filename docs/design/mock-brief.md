# 案5の絞り込み指示

`docs/design/variants.html` の**案5（白いスコアボード、白＋コバルト＋朱赤）**を採用した。これを1案だけの版に作り直す。

**雑でよい。速度優先。**検証やスクリーンショットは不要。

## 成果物

`docs/design/mock.html`。自己完結した単一HTML。

- 案の切り替えは不要（案5のみ）
- 幅の「375px」「全幅」切り替えは残す
- 外部リソースを読まない。CSS・JSはインライン。書体はシステムスタックのみ
- `<!DOCTYPE>` `<html>` `<head>` `<body>` は書かない。`<title>`、`<style>`、本文、`<script>` を直接書く
- データと配色は `variants.html` の案5からそのまま持ってくる

## 消すもの

1. 案の説明文「白いスコアボード。赤い確率バーと青い見出しで、試合後の一覧性を優先。」
2. 「Monte Carlo 100,000 trials」の表示
3. 行き先の説明（「1位 → Playoffs 準決勝へbye」のような対応表・注記）すべて
4. 表の中のチーム正式名称（`teamRow` の `<span class="formal">`）。略称と成績だけ残す
5. `probabilityCell` が数値と一緒に描いている図形（確率を表すバー／四角）。数値だけにする
6. 見出し「順位別の着地確率」
7. 注記「直通 = 1位 + 2位。バーの長さが確率の大きさを示し、取り得ない順位の0は打消し線で区別しています。残り試合は一律50%として計算。」

## 表のヘッダー

現在 `<thead>` が2行ある。

```
1行目: TEAM / 直通(1+2) / bye(1位) / PO1(2位) / PI2(3–4位) / PI1(5–6位)
2行目: 現在順位・成績 / % / 1位 / 2位 / 3位 / 4位 / 5位 / 6位
```

**1行目を丸ごと消す。**2行目だけを残し、その中の `%` を `Playoff` に変える。

```
現在順位・成績 / Playoff / 1位 / 2位 / 3位 / 4位 / 5位 / 6位
```

`table-layout: fixed` を使うなら、ヘッダーが1行になるので列幅指定の扱いに注意する。`<colgroup>` で指定しておくのが安全。

## グループの切り替え

**Alpha と Omega をタブで切り替える。同時に表示しない。**

- WAI-ARIA Tabs パターン。`role="tablist"` / `role="tab"` / `role="tabpanel"`、`aria-selected`、`aria-controls`
- 左右矢印キーで移動、選択中のタブだけ `tabIndex=0`（roving tabindex）
- 幅の切り替えボタンとは別のタブ列にする

## 残すもの

- 8列の表（チーム／Playoff／1〜6位）
- 確率ゼロを他の低い値と区別する表現（打消し線でよい）
- 案5の配色と書体
- 幅375pxで横スクロールしないこと
